## Why this line

The judge weighs, in order: (1) it reads as a commit message about a fix
that backfired, (2) it is genuinely funny, (3) it captures the specific
irony of a repair that broke more than it mended, (4) it sounds like a real
subject line, (5) it finds a fresh angle instead of the obvious ones about
reverting, testing in production, or breaking everything.

This line wins on the third criterion most of all: the "fix" does not merely
fail — it amplifies the exact bug it was meant to cure, in the exact same
dimension. Duplicate emails were the problem; the repair sends each one
twice, and faster. The irony is specific to this kind of fix — it could
only be about a repair that made the original bug worse — and it lands on
its own, with no explanation needed.
